# Design — Gestion d'établissement scolaire

- **Typo** : Poppins (300–700) partout. Titres 600, chiffres clés 600 en tabular-nums. Corps 14px, labels 12px uppercase tracking large.
- **Couleurs** (clin d'œil au drapeau djiboutien, en version sobre) :
  - Encre / sidebar : `#0E2433` (bleu nuit)
  - Fond : `#F5F4EF` (papier chaud) ; cartes `#FFFFFF`, bordures `#E7E4DA`
  - Primaire : `#1E6FA8` (bleu mer) ; ciel `#6AB2E7` pour accents légers
  - Succès / Soldé / Payé / Admis : `#12924A` ; Partiel : `#C98A12` ; Impayé / Conflit : `#C8372D`
- **Layout** : barre latérale fixe 264px (drawer sur mobile), modules groupés (Pilotage, Élèves, Personnel, Vie scolaire, Logistique, Finances). Contenu max 1400px, padding 32px desktop / 16px mobile.
- **Composants** : cartes à bord fin, rayon 14px, ombres quasi nulles. Tables denses à en-têtes collants, scroll horizontal sur mobile. Badges de statut pastel + point de couleur. Modale latérale (sheet) pour les formulaires.
- **Motion** : entrée de page en fondu + léger slide (stagger sur les KPI).
- **Montants** : toujours « 12 500 Fdj ».
